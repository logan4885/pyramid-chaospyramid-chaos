# Pyramid Chaos · MVP02（第三人称搞笑沙盒）

在 MVP01（第一人称生存）基础上换了方向：**第三人称 + 自由开放 + 搞笑抽象**。景区地图沿用，但不再有倒计时和结局，只有混乱本身。

## 运行
双击 `index.html`（Chrome / Edge / Safari，需 WebGL）。零依赖，无需服务器。**当前仅键鼠，未做触屏。**

## 操作
| 键 | 作用 |
|---|---|
| WASD / 鼠标 | 移动 / 转镜头 |
| Shift | 冲刺（步行）/ 加速（载具） |
| 空格 | 跳；骆驼上=跳跃；观光车/行李车=刹车；火箭背包=空中喷射 |
| E | 交互：上下车、向商贩买/租 |
| F | 用道具（自拍/喇叭/香蕉）；载具上无自拍杆时=按喇叭 |
| R | 主动摔倒（布娃娃） |
| Esc / M | 暂停 / 静音 |

## 玩法与系统
- **布娃娃物理**：所有人偶（含玩家）被撞、摔、炸飞后切换为 Verlet 布娃娃，可躺在金字塔台阶上，几秒后爬起来。
- **载具**：骆驼（可跳）、观光车、火箭行李车（Shift 喷射，有燃料）。撞墙过猛或落地过重会把你甩出去。斜坡跳台 4 个。
- **道具**（地上发光方块 / 纪念品摊 $10 抽）：自拍杆、空气炮喇叭、火箭背包、香蕉皮。
- **混乱分与连击**：撞飞路人、砸东西、腾空、自拍都得分，4 秒内连击最高 ×8，围观打赏会变成现金。
- **通缉系统**：撞人/偷骆驼/吹喇叭加热度。1 星起保安追你；3 星起援军增多；4–5 星**骆驼大军**出场“主持公道”。躲出视线一段时间星级下降；被抓会罚一半钱并送回入口。
- **自拍倍率**：空中 ×3、背景被保安追 ×2、背景有人躺平 ×2、骑骆驼 ×1.5、金字塔入镜 ×1.5、登顶 ×5……拍立得缩略图会显示本次标签。
- **7 个挑战**：金字塔打卡、空中自拍、人肉保龄球、滞空大师、骆驼冲线、全身而退、登顶金字塔（金字塔每层都能站，用跳台+火箭背包分两段飞上去）。
- 骆驼商人处 $15 租骆驼 2 分钟内偷骆驼不算偷。

## 已知限制 / 需要你试玩决定
- **没有真人试玩过**：手感（相机、车辆转向、布娃娃松紧、火箭背包推力）、通缉节奏、数值平衡都未调。
- 未做触屏；无存档（仅记录最高分）；音效为程序合成。
- 人偶/载具是低面数积木占位，无动画骨骼，行走与坐姿是程序姿态。
- 性能：近处约 900 次绘制调用，无头软渲染下只有约 10 FPS（不代表真实显卡），**真机帧率待测**；人多时布娃娃数量上限未做限制。
- 与 MVP01 的关系：独立文件夹，互不影响。
- 修复「开车撞物体→摔出→起身后角色不见」：撞击当帧残留的坐姿状态让角色被画成冻结在车座位上的幻影 (js/entities.js)
- 防「只剩影子」：角色任一数值（朝向/动画等）变 NaN 会整个不画。加了自动修复（console 会出现 `[自愈]`）；按 **T** 手动找回角色；按 **F3** 显示调试信息。
- 脚本加了版本号（`?v=`），避免浏览器缓存旧 JS；主菜单标题旁显示 build 号。

## 聊天气泡 + 房间在线玩家
- 游戏中按 **Enter** 打字，再按 Enter 发送：文字以气泡形式显示在小人头顶（所有同房间玩家可见）；Esc 取消。
- 右侧面板显示「房间号 / 在线人数 / 玩家列表 / 最近聊天」。命令：`/name 新昵称`、`/room 房间号`。
- 同一房间号的玩家互相可见（头顶昵称、实时位置/载具同步）。
- 联机方式：
  - **不装任何东西**：同一浏览器开多个标签页，填同一房间号即可互相看到、聊天。
  - **跨电脑/局域网/公网**：在游戏目录运行 `node server.js`（零依赖，Node 16+），所有人用浏览器打开 `http://服务器IP:8787`，会自动连接；也可在菜单“联机服务器”填 `ws://IP:8787`。

## 联机服务器（零依赖，只需 Node.js）
1. 安装 Node.js（https://nodejs.org，LTS 版）。
2. **Windows 双击 `启动联机服务器.bat`**（或命令行 `node server.js`，可加端口：`node server.js 9000`）。
3. 窗口里会打印地址，例如 `http://192.168.1.5:8787`：
   - 你自己和**同一 WiFi/局域网**的朋友直接用浏览器打开这个地址，进游戏即自动联机。
   - 同一房间才能互相看到；游戏内聊天框输入 `/room 房间名` 换房间，`/name 昵称` 改名。
4. **不在同一网络（远程朋友）**，任选其一：
   - 内网穿透（最快）：另开窗口运行 `cloudflared tunnel --url http://localhost:8787`（或 `ngrok http 8787`），把给出的 https 地址发给朋友即可（自动走 wss）。
   - 路由器端口映射 8787 → 本机，朋友访问 `http://你的公网IP:8787`。
   - 云托管：本目录带 `package.json`/`Procfile`/`Dockerfile`，可直接部署到 Render、Railway、Fly.io 等（启动命令 `node server.js`，监听 `PORT` 环境变量）。
5. 健康检查：`/health`。限制：每房间 16 人，最多 200 个房间。
同步内容：玩家位置/动作、载具、聊天；NPC、警察、世界事件各自本地模拟。
